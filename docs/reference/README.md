# 技术参考（Reference）

English: [README.en.md](./README.en.md)

## 这里存放什么

稳定的参考资料，例如：

- configuration reference；
- API reference；
- schemas；
- protocols；
- file formats。

## 不应该存放什么

- Proposal 或 Target Design；
- brainstorming 与临时讨论；
- 开发计划；
- 尚未确定的设想。

这里只放已经确定、相对稳定的事实性参考内容。

## 当前状态

- [upstream-auto-review.md](./upstream-auto-review.md) — 上游官方 Auto Review `0.2.1-rc.2` 的审查入口、上下文组装、来源分类、风险裁决与生命周期调研快照；本插件面板面的只读语义边界以此为据。

## 推荐命名

使用小写中划线命名，例如：

```text
<topic>.md
```
