# Reference

中文：[README.md](./README.md)

## What Belongs Here

Stable reference material, such as:

- Configuration reference;
- API reference;
- Schemas;
- Protocols;
- File formats.

## What Does Not Belong Here

- Proposals or target designs;
- Brainstorming and scratch discussions;
- Development plans;
- Unsettled ideas.

Only established, relatively stable factual reference content belongs here.

## Current State

- [upstream-auto-review.md](./upstream-auto-review.md) — a survey snapshot of the upstream official Auto Review at `0.2.1-rc.2`: review entry point, context assembly, source classification, risk adjudication, and lifecycle; the read-only semantic boundary this plugin's panel must respect.

## Naming Convention

Use lowercase kebab-case, for example:

```text
<topic>.md
```
