# 需求文档（Requirements）

English: [README.en.md](./README.en.md)

## 这里存放什么

- 产品需求；
- 功能需求；
- 非功能需求；
- Use Cases；
- 约束条件（constraints）。

## 不应该存放什么

- 架构设计（放入 `../architecture/`）；
- 实施计划（放入 `../plans/`）；
- 临时讨论或 brainstorming。
